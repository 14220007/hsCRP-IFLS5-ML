# data/

Folder ini sengaja kosong di GitHub. Data IFLS hanya boleh diunduh langsung dari RAND oleh pengguna terdaftar
dan tidak boleh disebarkan ulang. Letakkan isi `hh14_all_dta.zip` dan `hh14_dbs_dta.zip` di `data/raw/`,
lalu jalankan langkah di README utama. File CSV yang dihasilkan tetap di folder ini dan tidak ikut terunggah
karena tercantum di `.gitignore`.
